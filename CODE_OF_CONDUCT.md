# Code of Conduct

AISync follows the [Contributor Covenant Code of Conduct](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our pledge

We pledge to make participation in this project respectful and harassment-free for everyone, regardless of age, body size, disability, ethnicity, gender identity and expression, level of experience, education, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Expected behavior

- Be kind and direct.
- Assume good intent.
- Focus criticism on ideas and code, not people.
- Respect different experience levels.
- Help keep issues and pull requests actionable.

## Unacceptable behavior

- Harassment, insults, or discriminatory language.
- Sexualized language or attention.
- Trolling or sustained disruption.
- Publishing private information without permission.
- Any conduct that would be inappropriate in a professional setting.

## Enforcement

Maintainers may edit, hide, or remove comments, issues, pull requests, and other contributions that do not follow this code of conduct. Maintainers may also temporarily or permanently ban participants for behavior they deem inappropriate, threatening, offensive, or harmful.

## Reporting

Report code of conduct concerns privately to the project maintainer through GitHub profile contact methods. If the concern involves a maintainer, include enough context for an independent review by another trusted project participant when available.

Reports will be handled as privately as practical.
