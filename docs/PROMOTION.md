## Core message

AISync stops you from copying AI coding-agent instructions and skills between tools by hand. Edit once locally, then sync to Codex, Copilot, Pi, or custom targets.

## Short description

AISync is a local-first macOS app for managing AI coding-agent instructions and reusable skills in one place, with optional private GitHub backup.

## One-liner

Stop copy-pasting AI coding-agent instructions between tools.

## Longer note

AISync is for developers who use more than one AI coding tool and do not want to keep instruction files in sync manually.

It keeps global instructions and reusable skills in one local folder, then syncs them into Codex, Copilot, Pi, or custom targets with symlinks. It backs up replaced files and can optionally sync AISync-owned files through a private GitHub repository.

macOS download: https://github.com/mohammedhammoud/aisync/releases/latest
